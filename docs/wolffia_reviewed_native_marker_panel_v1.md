# Wolffia Reviewed Native Marker Panel v1

This note documents the frozen reviewed Wolffia-native marker panel v1.

The reviewed v1 panel is stored here:

```text
data/metadata/wolffia_reviewed_native_marker_panel_v1.csv
```

It is generated by:

```text
scripts/41_freeze_reviewed_native_marker_panel_v1.py
```

The public-data scoring notebook is:

```text
notebooks/14_public_wolffia_reviewed_marker_panel_v1_scoring.ipynb
```

## Purpose

The reviewed v1 panel is the current best Wolffia-native scoring reference. It converts the manual marker-review recommendations into a stable panel that can be reused for public data and future experimental datasets.

This panel does not replace full clustering, differential expression, or manual annotation. Instead, it provides a compact biological readout for broad Wolffia-native programs.

## Input

The reviewed panel is frozen from:

```text
data/metadata/wolffia_trusted_marker_panel_manual_review_recommendations.csv
```

Rows are retained if their manual recommendation is:

- `keep`
- `maybe`
- `unknown_interesting`

## Panel composition

The reviewed v1 panel contains:

- 60 marker-program rows
- 47 reviewed core markers
- 9 reviewed supporting markers
- 4 reviewed unknown-watchlist markers

Programs represented:

- Photosynthesis / light harvesting
- Carbon fixation / assimilation
- Chloroplast gene expression / plastid translation
- Ion / water balance
- Nutrient transport
- Stress / chaperone response
- Lipid / surface / cell-wall biology
- RNA-binding / regulatory
- Unknown high-ranking marker

## How to use v1 for future data

Future normalized/log1p Waus8730 `.h5ad` files can be scored with:

```bash
python scripts/40_score_future_wolffia_dataset.py \
  /path/to/future_wolffia_normalized_log1p.h5ad \
  --panel data/metadata/wolffia_reviewed_native_marker_panel_v1.csv \
  --metadata /path/to/future_metadata.csv \
  --metadata-cell-id-column cell_id \
  --group-columns condition,sample_id,replicate,cluster,leiden \
  --output-dir /path/to/output/reviewed_v1_scores
```

For salt-stress data, the most important comparisons will be:

- control versus salt treatment
- replicate consistency
- stress/chaperone score shifts
- ion/water-balance score shifts
- photosynthesis and carbon-fixation score shifts
- emergence of unknown-marker or Wolffia-specific states

## Caveats

- This is v1, not a permanent final annotation reference.
- The unknown-watchlist genes should not be assigned named biology yet.
- Some markers are retained as supporting markers because they are plausible but not perfectly specific.
- Future experimental data may justify adding, removing, or reassigning markers.
