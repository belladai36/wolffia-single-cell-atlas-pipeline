# Wolffia Marker-Panel Review and Future Dataset Scoring

This note documents the three-step refinement after building the trusted Wolffia-native marker panel.

## 1. Structured marker review

The review table is:

```text
data/metadata/wolffia_trusted_native_marker_panel_review.csv
```

It is generated by:

```text
scripts/39_build_trusted_marker_review_table.py
```

The table keeps the 60 first-pass trusted marker rows and adds practical review columns:

- `initial_review_call`
- `manual_review_priority`
- `review_note`
- `manual_decision`
- `manual_decision_notes`

Current first-pass calls:

- 46 `keep_initial`
- 9 `supporting_review`
- 5 `unknown_watchlist`

Current review priorities:

- 29 high-priority rows
- 26 medium-priority rows
- 5 watchlist rows

The blank `manual_decision` columns are intentional. They are where a reviewer can later mark genes as `keep`, `maybe`, `remove`, or `unknown_interesting`.

## 2. Marker-level visualization review

The marker-review notebook is:

```text
notebooks/13_public_wolffia_marker_panel_review.ipynb
```

It was executed on the four public Waus8730 runs and writes lightweight summaries:

```text
data/metadata/wolffia_trusted_marker_panel_review_summary.csv
data/metadata/wolffia_trusted_marker_panel_cluster_summary.csv
```

The notebook creates:

- dawn/dusk marker-expression heatmaps
- marker-by-cluster dot plots
- representative marker UMAP overlays
- marker-level expression and detection summaries

These visualizations help decide whether each marker should remain in the trusted panel.

## 3. Future Wolffia dataset scoring template

The reusable scoring script is:

```text
scripts/40_score_future_wolffia_dataset.py
```

It can be applied to future normalized/log1p Waus8730 `.h5ad` files, including control versus salt-stress data.

Example:

```bash
python scripts/40_score_future_wolffia_dataset.py \
  /path/to/future_wolffia_normalized_log1p.h5ad \
  --metadata /path/to/future_metadata.csv \
  --metadata-cell-id-column cell_id \
  --group-columns condition,sample_id,replicate,cluster,leiden \
  --output-dir /path/to/output/trusted_native_program_scores
```

The script writes:

```text
trusted_native_program_cell_scores.csv
trusted_native_program_gene_coverage.csv
trusted_native_program_score_summary.csv
```

## How this prepares the salt-stress analysis

When future control versus salt-stress Wolffia data are available, the project can now:

1. process reads into a Waus8730 gene-by-cell matrix
2. normalize the matrix
3. score each cell with the trusted native marker panel
4. summarize scores by condition, sample, replicate, and cluster
5. test whether stress, ion/water balance, photosynthesis, nutrient transport, or unknown-marker programs shift under treatment

This makes the analysis more Wolffia-native and less dependent on forcing Arabidopsis-derived labels onto every cell.
