# Wolffia Trusted Native Marker Panel

This note documents the first-pass trusted Wolffia-native marker panel.

The panel is stored here:

```text
data/metadata/wolffia_trusted_native_marker_panel.csv
```

It is generated by:

```text
scripts/38_build_trusted_native_marker_panel.py
```

The scoring notebook is:

```text
notebooks/12_public_wolffia_trusted_marker_panel_scoring.ipynb
```

## Purpose

The broader native marker-program candidate table is useful for discovery, but it contains many genes that still need manual interpretation.

The trusted panel is a smaller, more practical marker set for scoring future Wolffia datasets. It is designed to be useful for:

- checking reproducible Wolffia-native programs in public data
- interpreting cells that remain ambiguous under Arabidopsis transfer
- preparing a baseline marker-score framework for future control versus salt-stress data

## First-pass selection logic

The current panel was built using transparent computational rules:

- `core_marker`: high-evidence marker with top-five rank in at least one native Wolffia cluster
- `supporting_marker`: high- or medium-evidence marker within the top-eight ranks
- `watchlist_unknown`: strong Wolffia marker with unknown or unclear annotation

The panel keeps at most eight marker rows per program in this first pass.

## Current panel size

The first-pass panel contains:

- 60 marker-program rows
- 46 core markers
- 9 supporting markers
- 5 unknown-marker watchlist entries

All trusted-panel genes are present in the current Waus8730 public expression matrix.

## Current scoring result

The trusted panel was applied to 11,084 cells across four public Waus8730 runs.

The broad pattern is consistent with the larger candidate-marker scoring layer:

- dawn-group cells have higher photosynthesis/light-harvesting, carbon-fixation, and chloroplast gene-expression scores
- dusk-group cells have higher nutrient-transport, RNA-binding/regulatory, and stress/chaperone-response scores

These results are exploratory. They suggest reproducible marker-program structure in the public Wolffia data, but they should not yet be treated as final cell-state annotation.

## How to use this panel

For future Wolffia datasets, including control versus salt-stress experiments:

1. process the raw data into a Waus8730 gene-by-cell count matrix
2. normalize the matrix using the same workflow as the public data
3. score cells using this trusted marker panel
4. compare program scores by sample, replicate, condition, and cluster
5. inspect whether stress, ion/water balance, photosynthesis, and unknown-marker programs shift under treatment

## Caveats

- This is still a first-pass computational panel.
- The panel depends on current Waus8730 functional annotation.
- Unknown-marker rows are useful for tracking Wolffia-specific patterns, but they are not named biological programs yet.
- Manual review should happen before using the panel as a final annotation reference.
